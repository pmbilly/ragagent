Embed Widget 测试页

功能特性

嵌入渠道是一段可配置的网页挂件：宿主页面加一行脚本即可使用，外观与能力全部由渠道配置决定。

一行脚本接入

引入 ragagent-widget.js 并声明渠道与密钥即可运行；渲染在 iframe 内，不受宿主页面样式影响，也不反向污染宿主。

渠道级外观

主色、面板标题、浮标图片、面板尺寸（data-width / data-height）以及四个角的位置（data-position）均可单独配置。

免登录访客会话

访客无需账号即可对话；会话落库，刷新或重开面板可恢复历史，会话票到期自动换取新票并重放请求。

两种安全接入方式

静态发布密钥，或「安全模式」由宿主服务端经 data-token-endpoint 换取短期会话票；叠加 Origin 白名单与按分钟 / 按天的调用限流。

多语言

界面语言优先级：宿主指定（data-locale 或 init({locale})）> 渠道默认语言 > 浏览器语言。

能力随渠道开关

联网搜索、文件 / 图片上传、思考过程展示、猜你想问，均按渠道（并与智能体能力交叉）决定是否出现在输入区。

知识范围随智能体

回答依据渠道所绑定智能体的知识库与提示词配置，换渠道即换知识与话术，宿主页面无需改动。

流式回答与引用溯源

回答增量流式渲染并支持 markdown；正文引用可点开浮层查看来源片段，链接在新窗口打开。

宿主可控的 JS API

全局 WeKnora 提供 init / open / close / toggle / setContext / openWithQuery / setLocale，可把挂件接到自有按钮、路由或页面上下文上。

验收清单

依据：该渠道公开配置 GET /api/v1/embed/{channel}/config + widget 代码；括号内是该渠道当前值。

A. 外观与启动

  • 右下角圆形启动按钮，底色 = 渠道主色 #31ccd3（渠道配置优先于 data-primary-color；该属性只负责首帧绘制与请求失败兜底）
  • 启动按钮图标取渠道 launcherIcon（当前为 webp）；未配置时才回落默认白色气泡 SVG
  • 点击展开面板，默认尺寸 420 × 720（可用 data-width / data-height 覆盖）
  • 位置取 data-position（后台「浮标位置」生成该属性，当前 bottom-right）；widget 自身不读渠道的 widgetPosition
  • 面板头部：徽标同样用 launcherIcon（缺省回退智能体头像 / 默认图标）；标题 = displayTitle「AION 小埃」（headerTitleMode=channel；切成 session 时显示会话标题）
  • 欢迎语：welcomeMessage 为空 ⇒ 不应出现欢迎气泡；配置后显示在首条用户消息之前，用户发言后消失
  • 头部右侧按钮：历史（打开历史会话抽屉）、新对话（无消息时禁用）

B. 问答主链路

  • 用户消息气泡：主题色底 + 白字（底色取渠道 primaryColor，未配置时回落灰底）
  • 回答流式输出；完成后按 markdown 渲染（标题/列表/表格/代码），图片经安全渲染显示
  • 思考过程：showThinking=false（当前）⇒ 只见三点闪烁；开 才出现可展开的思考卡片
  • 引用：悬停或点击正文引用标记 → 浮层显示来源片段（GET /api/v1/embed/{channel}/chunks/{chunkId}）；联网来源的链接新窗口打开
  • 开场猜问：渠道 showSuggestedQuestions=true + 智能体开场问题开关开（当前 true）⇒ 打开面板显示建议问题网格（GET /api/v1/embed/{channel}/suggested-questions），点击直接提问；用户发言后不再显示
  • 追问建议：需渠道开关 + 智能体追问开关同时开；当前 agentFollowUpQuestionsEnabled=false ⇒ 回答后不应出现追问建议（开启后才有，且仅当该消息允许换一批时出现「换一批」）

C. 按开关应收敛的入口

  • 联网搜索：渠道 allowWebSearch 与智能体 agentWebSearchEnabled 需同时为真才出现；当前两者皆 false ⇒ 输入区不出现
  • 文件 / 图片上传：渠道 allowFileUpload 与智能体 agentImageUploadEnabled 需同时为真才出现；当前两者皆 false ⇒ 输入区不出现

D. 会话、历史与异常

  • 首次打开：历史加载中显示骨架，不白屏；历史经 GET /api/v1/embed/{channel}/messages/{sessionId}/load 拉取，顺序正确、不重复
  • 历史抽屉：列出本访客在该渠道的会话（GET /api/v1/embed/{channel}/sessions）；点击切换，回答进行中切换会先弹确认（会中断当前回答）
  • 会话票：30 分钟有效（Redis embed:session:*）；过期后 401 → 自动换取新票并重放请求，界面无感
  • 安全模式（data-token-endpoint）：经 POST /api/v1/embed/{channel}/exchange 换取短期会话票并到期刷新；本页用的是静态 publish token
  • origin 校验：未列入 allowedOrigins 的页面请求被拒（origin not allowed）；当前只放行 http://localhost:5173
  • 限流：按「渠道 + 客户端 IP」每分钟、渠道全局每分钟、渠道每天三段校验，超限返回 429；这三个值不在公开 config 里，当前渠道为 100 次/分、20000 次/天（在后台渠道详情核对）

说明

本页与 widget 脚本同源（均来自 vite dev server，脚本为 /ragagent-widget.js。页面 origin 需已加入渠道的 Allowed Origins， 否则会报 origin not allowed。

外观与开关的最终取值以渠道配置为准；data-primary-color / data-title 只影响首帧绘制与启动按钮的无障碍标签（当前与渠道一致：#31ccd3 / 「AION 小埃」）。

widget 支持的全部 data-*： channel、token、token-endpoint、base-url、 position（四角）、width、height、primary-color、 title、locale、sandbox（true 时给 iframe 加 allow-scripts allow-forms allow-popups allow-modals allow-same-origin；跨源嵌入默认也会加）。

语言优先级：宿主声明（data-locale 或 init({locale})）> 渠道默认语言（当前为空 = 不指定）> 浏览器语言。
