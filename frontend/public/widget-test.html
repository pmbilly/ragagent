Embed Widget 测试页

验收清单

依据：该渠道公共配置 GET /api/v1/embed/{channel}/config + widget 的 data-*，与 2026-10-12 实测一致。

A. 外观与启动

  • 右下角圆形启动按钮，底色 = 渠道主色 #31ccd3（渠道配置优先于 data-primary-color；该属性只负责首帧绘制与请求失败兜底）
  • 按钮用渠道自定义图标 launcherIcon（当前为 webp）；未配置时才回落默认白色气泡 SVG
  • 点击展开面板，默认尺寸 420 × 720（可用 data-width / data-height 覆盖）
  • 面板标题 = 渠道 displayTitle「AI 小埃」（headerTitleMode=channel，与本页 data-title 一致）
  • 欢迎语：当前渠道 welcomeMessage 为空 ⇒ 不应出现欢迎气泡（后台配置后应在首条消息前显示）

B. 问答主链路（该渠道已绑定 Agent）

  • 用户消息气泡：主题色底 + 白字（底色取渠道 primaryColor，未配置时回落灰底）
  • 回答流式输出；完成后按 markdown 渲染（标题/列表/表格/代码），图片经安全渲染显示
  • 思考中：渠道「显示思考过程」关（当前）⇒ 只见三点闪烁；开 ⇒ 「思考中」折叠卡片、展开为 markdown
  • 引用：点击正文引用标记 → 浮层显示来源（取自 /api/v1/embed/{channel}/chunks/{chunkId}），浮层链接新窗口打开
  • 猜问：渠道开关开（当前）⇒ 打开面板显示建议问题网格、点击直接提问；回答后出现追问建议且可「换一批」

C. 按渠道开关应「不出现」的入口

  • 联网搜索开关：allowWebSearch=false ⇒ 输入区不得出现（渠道打开后才出现，且切换状态在刷新后保持）
  • 文件 / 图片上传：allowFileUpload=false 且 Agent 图片上传关闭 ⇒ 输入区不得出现（两者都开时才出现）

D. 会话与异常

  • 首次打开：历史加载中显示骨架，不白屏；历史经 /api/v1/embed/{channel}/messages/{sessionId}/load 拉取，顺序正确、不重复
  • 页面 origin 未列入渠道 allowedOrigins 时请求被拒（origin not allowed）；当前已含 http://localhost:5173
  • 安全模式（data-token-endpoint）：经 POST /api/v1/embed/{channel}/exchange 换取会话 token 并到期刷新；本页用的是静态 publish token

说明

本页与 widget 脚本同源（均来自 vite dev server），页面 origin 为 http://localhost:5173，需已加入渠道的 Allowed Origins， 否则会报 origin not allowed。

widget 支持的全部 data-*： channel、token、token-endpoint、base-url、 position、width、height、primary-color、 title、locale、sandbox。

渠道配置复核（token 取本页 data-token）：
curl -s -H 'Origin: http://localhost:5173' -H 'Authorization: Embed <publish token>' http://localhost:8083/api/v1/embed/045bfd4b-81f6-4810-afdd-4df1256cb0de/config
